# Café Brétema (demo website)

A demo website for a fictional café in A Coruña, Spain. Café Brétema is not a real business, the phone number is made up, and the photos are from Unsplash.

**Live:** https://jlonguilope1.github.io/cafe-bretema/

## What it includes

- Spanish and English versions
- Menu with prices
- Opening hours that show whether the café is open right now
- Google Maps map and directions link
- Call and directions bar on mobile

## Built with

Plain HTML, CSS and JavaScript in a single file. No frameworks and no server, hosted on GitHub Pages.
